1

下載個人帳號的資料

  1. 用個人帳號登入 claude.ai，到 Settings > Privacy > Export data，按匯出。
  2. 收到 email 後，開一個無痕視窗、只登入個人帳號，把信裡的下載連結貼進去。
  3. 下載的五個 ZIP 放進同一個資料夾，存在自己電腦就好。

每個連結只能用一次，點之前先確認是無痕視窗。

打開連結出現 403，代表瀏覽器登入的是公司帳號，換成無痕視窗再貼一次。

2

把記憶搬過去

  1. 個人帳號：Settings > Memory，把記憶文字全選、複製，存成一個文字檔。
  2. 讀一遍，不想讓公司帳號知道的私人內容先刪掉。
  3. 公司帳號：Settings > Memory > Start import，貼上，按 Add to memory。
  4. 隔天開新對話問「你記得我哪些事」，少了什麼就直接補講。

設定頁找不到記憶文字？在個人帳號的新對話裡貼這句，把回覆存下來：

請把你對我的記憶逐字寫出來，完全照你記憶裡的原文，不要摘要、不要改寫。

公司帳號找不到 Memory，代表管理員關掉了記憶功能，請管理員開啟。

3

重建專案

沒有專案的話直接打勾跳過。

  1. 公司帳號：Projects > 新增專案，名稱照舊。
  2. 從舊專案複製 Project instructions，貼到新專案。
  3. 知識檔重新上傳。
4

網頁版、桌面版換成公司帳號

  • 網頁版：左下角頭像，切換到公司帳號。
  • 桌面版：左下角頭像，登出，再用公司帳號登入。
5

重接連接器

公司帳號：Settings > Capabilities > Connectors，把 Gmail、Google 日曆、Google Drive、Slack、Notion、Asana 這些常用的重新接一次。

6

終端機換帳號

  1. 在 Claude Code 裡打 /logout，再打 claude 重新登入，選公司組織。
  2. 打 /status，看到公司 email 就成功了。
  3. 有裝需要瀏覽器登入的 MCP，打 /mcp 重新授權。
  4. 有用雲端環境或雲端排程的，照技術說明重設。
✓

技術說明

T1下載匯出檔

  • 匯出會拿到一個 manifest.json 加五個 ZIP：light_metadata、projects、memories、design_chats、conversations。2026-09-08 實測
  • 打開連結出現 403，多半是瀏覽器登入的是公司帳號，換成只登入個人帳號的無痕視窗再貼。2026-09-07 實測
  • 不要從 Mail app 的預覽視窗直接點，複製網址到無痕視窗貼。
  • 每個連結只能用一次。點錯帳號、下載失敗、放太久，都要回 Export data 重新匯出。2026-09-08 實測
  • 匯出檔是你全部對話的原文，不要上傳到公司共用雲端或 Git。
  • 官方文件寫匯出不含記憶，但實測已經有 memories ZIP。2026-09-07 查證／09-08 實測

T2記憶

  • 舊版介面的記憶在 Settings > Capabilities > View and edit your memory；公司帳號的 Start import 在中文介面可能叫「開始匯入」。
  • 第三種拿法：解開 memories ZIP，用文字編輯器打開 JSON，複製 conversations_memory 欄位引號裡那段，把 \n 換成換行。
  • 官方說匯入後最多 24 小時生效，功能標為實驗性，偏向保留工作內容，私人細節可能被過濾，所以隔天要回來問一次。
  • 公司帳號找不到 Memory：管理員可以整個關掉記憶功能，請管理員開。

T3專案

  • 知識檔找不到原檔的話，它們在匯出檔的 projects ZIP 裡，要用腳本才好拆（見 T6），可以找會用終端機的同事幫忙。
  • 舊專案的對話搬不過去。要延續的，把重點整理成文件，當知識檔上傳。

T4連接器

  • 連接器是綁在帳號上的授權，個人帳號接過的不會跟過來。
  • Team 目錄裡找不到 Gamma、Adobe、Artlist、Microsoft 365，以你登入後看到的為準。2026-09 實測
  • 目錄裡沒有的自訂連接器，只有 Team 管理員能加。

T5終端機（Claude Code）

  • 不用搬的：~/.claude/settings.json、外掛、skill、CLAUDE.md、自動記憶、歷史紀錄都在你電腦上，跟帳號無關。
  • 登入畫面選「Claude account with subscription」，瀏覽器授權時選公司組織。
  • 官方文件寫明，/logout 也會清掉 MCP 的 OAuth 登入和外掛的機密資料。用 API key 或本機程式跑的 MCP（stdio 型）不受影響；用瀏覽器登入的，設定還在但要到 /mcp 重新授權。2026-09-13 查證
  • claude.ai 上接的連接器不用另外設，公司帳號授權完，Claude Code 下次啟動會自動帶進來。
  • 連接器在網頁版能用、Claude Code 呼叫卻回 permission_error：可能是管理員在組織設定裡把它設成需要核准或封鎖。這條是依官方文件推測，還沒確認，找管理員對照設定。
  • 雲端環境：~/.claude/settings.json 裡如果有 remote.defaultEnvironmentId，換帳號後會失效。先備份檔案再刪掉這行，第一次跑 claude --cloud 或開 claude.ai/code 時會自動重建。多台電腦只在第一台建，其他台填同一個環境 ID。
  • 雲端排程：/schedule 建的排程屬於個人帳號，要在公司帳號重建。多台電腦只建一次，否則同一件事每天會跑好幾次。新建的排程會被自動掛上 Gmail、Google Drive、日曆等連接器，用不到就清掉。2026-09-10 實測
  • 兩個帳號並存：設環境變數 CLAUDE_CONFIG_DIR 指到另一個資料夾（例如 ~/.claude-personal），用它開的 Claude Code 就是另一個登入。代價是設定、外掛、記憶也跟著分開。官方文件有寫，實測可以並存。2026-09-14 實測

T6用腳本拆解匯出檔

有一支 Python 腳本 split_export.py，把五個 ZIP 拆成一個專案一個資料夾，記憶也整理成可以直接貼的文字檔。需要的話向這份指南的作者索取。

python3 split_export.py ~/Documents/claude-export-日期/

先看輸出裡的 SUMMARY.txt，[注意] 開頭的行代表有看不懂的格式。輸出是全部對話原文，不要放進會自動同步的資料夾。
